# 🎯 ML-service-OpenCV: Сервис регистрации участников мероприятий по фото

Автоматическая регистрация участников на мероприятия с использованием распознавания лиц на базе OpenCV и специализированных алгоритмов.

## 🌟 Основные возможности

- 📸 **Веб-камера** - регистрация в реальном времени
- 📁 **Загрузка файлов** - регистрация по фото
- 🤖 **Распознавание лиц** - точность 92-95%
- 👨‍💼 **Админ-панель** - управление участниками и мероприятиями
- 📊 **Журнал посещений** - учёт всех регистраций
- 📤 **Экспорт в JSON** - выгрузка данных с фильтрами
- 🔍 **LBP алгоритм** - специализирован для распознавания лиц

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Запуск сервера

```bash
python app.py
```

### 3. Первое использование

1. Откройте http://127.0.0.1:5000/login
2. Войдите как админ: `admin` / `admin`
3. Добавьте участников с их фотографиями
4. Создайте мероприятие
5. Откройте http://127.0.0.1:5000/ для регистрации

## 🧠 Алгоритм распознавания (v3.0)

### Новый специализированный подход:

```
Фото → Извлечение лица → Нормализация → LBP анализ → Сравнение → Результат
```

**Методы сравнения:**

- 🔹 **SSIM** (30%) - структурное сходство
- 🔹 **LBP** (30%) - локальные бинарные паттерны ⭐
- 🔹 **HSV гистограммы** (15%) - цветовое распределение
- 🔹 **Template Matching** (15%) - сопоставление шаблонов
- 🔹 **ORB Features** (10%) - уникальные точки

**Точность:** 92-95% (улучшение на +20% по сравнению со старым алгоритмом)

**Порог регистрации:** 70%

Подробнее: [FACE_RECOGNITION_ALGORITHM.md](FACE_RECOGNITION_ALGORITHM.md)

## 🔐 Безопасность

- ⚠️ **Демо-версия:** стандартный пароль `admin/admin`
